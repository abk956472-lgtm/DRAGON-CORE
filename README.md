
# 🐉 DRAGON-CORE

### Emergency Network Connectivity System

**Developer:** DRAGON  
**Version:** 1.0.0  
**Status:** Development

## About
DRAGON-CORE is an experimental emergency connectivity project designed to monitor network availability and manage backup connections.

## Main Objectives
- Monitor 4G network connectivity.
- Detect internet outages.
- Test available network routes.
- Manage authorized backup tunnels.
- Maintain a five-minute emergency monitoring session.

## Technology
- Python
- WireGuard
- GitHub Actions
- Network Monitoring
